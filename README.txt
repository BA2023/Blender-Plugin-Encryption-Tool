Blender插件加密工具
===================

版本：v26.6.25

启动方式：
1. 双击“Start Tool.bat”
2. 或者把一个 .py 脚本文件直接拖到这个 bat 上

功能：
- 支持在界面里拖入 .py 脚本
- 支持点击按钮选择脚本
- 支持切换 Python 3.10 ~ 3.14
- 自动把 Blender 插件打包为“壳层 __init__.py + 核心 .pyd”的 zip

输出目录：
output

注意：
- 当前 3.10 / 3.11 / 3.12 / 3.13 / 3.14 已就绪
- Python 3.10 ~ 3.14 和编译器均在工具目录内，复制时请完整保留。
